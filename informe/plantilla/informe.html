About this report

This report presents the same results as the paper of the same title, in a form meant for policy and general readers. Where the two differ in wording, the paper is the reference. Illustrations are original and were generated for this report; they carry no data.

Produced with the support of INPLUX S.A.S., Medellín.

Data and code

Dataset and code, version 2026.1: Zenodo, doi:10.5281/zenodo.23552918 (all versions: doi:10.5281/zenodo.23552917). Repository: github.com/Cespial/delegation-divide. Static JSON for every occupation and country: cespial.github.io/delegation-divide/adi/v2026.1/. Python package adi-index and MCP server adi-mcp.

Preregistration

Hypotheses, rubric and analysis plan were registered before the main scoring run: OSF, doi:10.17605/OSF.IO/9ZNTF. The rubric file carries a SHA-256 hash that the scoring script checks before it runs. Deviations from the registered plan are listed in the repository.

Reproducibility

Every number in this report is read by identifier from the published outputs, salidas/claims.jsonl and the country table salidas/indice_pais_detalle.csv; no number is typed by hand. The report, the paper and the dataset are built from the same files by one script.

Ten things to know

The Agent Delegability Index rates every one of {{ c("cobertura.tareas") }} occupational task statements for how much of it a current AI agent could carry out, and carries the ratings to {{ c("cobertura.isco") }} occupations and {{ c("cobertura.paises") }} countries.

  1. 1

    About a third of the world's working time is at least partly delegable to AI agents. {{ c("titular.global.l2") }}% of task time in world employment can be partly handed to an agent in 2026 (95% interval {{ c("titular.global.l2.lo") }}–{{ c("titular.global.l2.hi") }}%), across {{ c("cobertura.empleo_millones") }} million workers.

  2. 2

    Full delegation is rare. Only {{ c("titular.global.l3") }}% of task time can be handed over in full. Partial delegation is the most common rating of a task ({{ c("tareas.nivel2.pct") }}% of statements), full delegation the least common ({{ c("tareas.nivel3.pct") }}%).

  3. 3

    Delegable work rises with income: the delegation divide. The index goes from {{ c("titular.ingreso.bajo.l2") }}% in low-income countries to {{ c("titular.ingreso.alto.l2") }}% in high-income countries, {{ c("h1.pendiente") }} percentage points for each log point of GDP per capita (R² = {{ c("h1.r2") }}, {{ c("h1.n") }} countries).

  4. 4

    The divide comes from what people do, not from where they do it. Poorer countries employ more people in farming, crafts and elementary jobs, where the physical barrier is flagged on {{ c("gg.9.barrera_fisica.pct") }}% of task weight in elementary occupations against {{ c("gg.1.barrera_fisica.pct") }}% for managers.

  5. 5

    Office work is the most delegable. Managers reach {{ c("gg.1.l2") }}% and clerical support workers {{ c("gg.4.l2") }}%; elementary occupations reach {{ c("gg.9.l2") }}%. {{ c("extremo.isco.n.max") }} unit groups, led by coding and proof-reading clerks, are delegable on every task.

  6. 6

    Countries range from Burundi to Singapore. The index runs from {{ c("extremo.pais.bot1.l2") }}% in Burundi to {{ c("extremo.pais.top1.l2") }}% in Singapore. Colombia stands at {{ c("pais.COL.l2") }}%, Mexico at {{ c("pais.MEX.l2") }}%, Brazil at {{ c("pais.BRA.l2") }}% and the United States at {{ c("pais.USA.l2") }}%.

  7. 7

    Delegation tracks exposure, and adds levels and barriers to it. Across occupations the index correlates with earlier exposure measures at r = {{ c("h3.r.eloundou") }} and {{ c("h3.r.felten") }}, above the preregistered bound of 0.80. What ADI adds is how far delegation goes, what stops it, and global reach.

  8. 8

    Full delegation peaks for tasks of about twelve minutes. The chance that an agent can finish a task alone rises with task length up to about {{ c("h4.pico.minutos") }} minutes of human time and falls after it.

  9. 9

    Use follows delegability. Across {{ c("h2.n") }} countries, observed AI use correlates with the index at r = {{ c("h2.r.adi_uso") }}. The preregistered adoption gap in middle-income countries is not supported ({{ c("h2.brecha.medio.p", "p") }}).

  10. 10

    The ratings hold up against people and agents. The two rating models agree at κ = {{ c("agree.kappa.sonnet_haiku") }}; a blind human rating of {{ c("n.humano") }} tasks agrees with them at κ = {{ c("agree.kappa.humano.modelo") }}, and an agentic panel with web search at κ = {{ c("agree.kappa.panel.modelo") }}. Data, prompts and tools are open.

The Delegation
Divide

Most measures of artificial intelligence and work ask which jobs are exposed. This report asks how much of each task an AI agent can take over, from helping a person to finishing the job alone, and what stops it.

It rates {{ c("cobertura.tareas") }} task statements, maps them to {{ c("cobertura.isco") }} occupations and weights them by employment in {{ c("cobertura.paises") }} countries. The result is an open index, an atlas and a set of tools that people and AI agents can query and cite.
