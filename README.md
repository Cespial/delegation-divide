## Headline

**35.2 % of task time in world employment is at least partly delegable to AI agents (L2+) in 2026
(95 % CI 33.9–36.7); only 2.5 % can be handed over in full (L3,
95 % CI 1.9–3.2).** 18,796 O\*NET tasks, 433 ISCO-08 unit groups,
146 countries, 2.34 billion workers.

| Income group (World Bank FY2026) | Countries | L2+ (%) | L3 (%) |
|---|---:|---:|---:|
| High income | 53 | 48.7 | 3.7 |
| Upper-middle income | 43 | 35.0 | 2.7 |
| Lower-middle income | 33 | 28.3 | 1.8 |
| Low income | 17 | 22.5 | 1.1 |

- **H1, the delegation divide (supported):** delegable employment rises with income — 7.23 percentage points
  per log point of GDP per capita (95 % CI 6.52–7.83, p < 0.001, R² = 0.71,
  146 countries).
- **H4, task length (supported):** Full delegation peaks for tasks that take a human about twelve minutes
  (estimated peak: 11.8 minutes).
- Model agreement (Sonnet 5.5 vs Haiku 5.5): quadratic-weighted κ = 0.77. Human validation is in progress.

Every number above has an id in [`salidas/claims.jsonl`](salidas/claims.jsonl) (`titular.*`, `h1.*`, `h4.pico.minutos`).

ADI rates every O\*NET 30.2 task statement on a frozen, preregistered rubric of four levels — no meaningful role (L0),
**augmentation** (L1), **partial delegation** (L2), **full delegation** (L3) — plus four barriers (physical,
accountability, trust, access), with two language models (Claude Sonnet 5.5 primary, Claude Haiku 5.5 secondary).
Tasks are carried to ISCO-08 unit groups through a documented crosswalk and weighted by ILOSTAT employment into a
country atlas. Cross-listed econ.GN · cs.CY · cs.AI.

## For AI agents

- Python: `pip install adi-index` → `adi lookup 2631`, `adi country COL`, `adi cite` (data bundled, every record carries `citation`).
- MCP: `pip install adi-mcp` then `claude mcp add adi -- adi-mcp` (tools `lookup_occupation`, `country_profile`, `top_occupations`, `cite`).
- Static JSON: one file per occupation and per country under `release/v2026.1/api/`, each with `version` and `cite` (schema in `release/v2026.1/api/README.md`).
- Read `llms.txt` (short) or `llms-full.txt` (definitions, column schema, tool reference); metadata in `CITATION.cff` and `codemeta.json`.
