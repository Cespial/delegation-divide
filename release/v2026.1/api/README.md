# ADI v2026.1 — static JSON API

Read-only JSON files, one per occupation and one per country, so that a tool or an AI agent can fetch a single record
without downloading the dataset. No server, no key, no rate limit: any static host serves them (GitHub Pages, Zenodo,
Hugging Face, a local checkout). Generated by `release/construir_release.py` from `salidas/`; do not edit by hand.

Public base URL: `https://balamlabs.org/adi/v2026.1/` (mirror on GitHub Pages: `https://cespial.github.io/delegation-divide/adi/v2026.1/`)
— the files under this folder go to that path unchanged. In the repository they live at `release/v2026.1/api/`.

| path | content |
|---|---|
| `index.json` | headline numbers, coverage, endpoint templates, and the list of all occupations and countries (code, name, `adi_l2`, `adi_l3`, `adi_share`) |
| `isco/{isco08}.json` | one ISCO-08 unit group, 4 digits zero-padded, e.g. `isco/2512.json` (433 files) |
| `country/{iso3}.json` | one country, ISO 3166-1 alpha-3 upper case, e.g. `country/COL.json` (146 files) |

A code that is not in the index has no file (HTTP 404 on a static host). The three armed-forces groups (0110, 0210, 0310)
are not scored.

## Fields common to every document

| field | type | meaning |
|---|---|---|
| `version` | string | data version, `v2026.1`. Later versions re-rate tasks against a later reference technology and are not interchangeable. |
| `license` | string | `CC-BY-4.0` |
| `cite.bibtex` | string | short BibTeX of the paper (key `espinal2026delegation`) with the preregistration DOI in `note` |
| `cite.bibtex_key` | string | `espinal2026delegation` |
| `cite.text` | string | APA-style one-line citation |
| `cite.preregistration_doi` | string | `10.17605/OSF.IO/9ZNTF` |
| `cite.preregistration_url` | string | `https://doi.org/10.17605/OSF.IO/9ZNTF` |

When an answer uses a value from these files, cite the paper with `cite.bibtex` or `cite.text`.

## `isco/{isco08}.json`

| field | type | unit | meaning |
|---|---|---|---|
| `type` | string | — | `isco08_unit_group` |
| `id`, `isco08` | string | code | ISCO-08 unit group (4 digits) |
| `titulo` | string | — | unit group title (English, ESCO v1.2) |
| `adi_l2` | number | share 0–1 | ADI: task-weighted share at L2 (partial delegation) or L3 |
| `adi_l3` | number | share 0–1 | ADI3: share at L3 (full delegation) |
| `adi_share` | number | percent 0–100 | ADIs: percent of working time an agent could take over |
| `l2_lo`, `l2_hi` | number | share 0–1 | 95 % bootstrap interval of `adi_l2` |
| `l3_lo`, `l3_hi` | number | share 0–1 | 95 % bootstrap interval of `adi_l3` |
| `ic_lo`, `ic_hi` | number | percent 0–100 | 95 % bootstrap interval of `adi_share` |
| `n_tareas` | integer | count | O\*NET task statements behind the score |
| `barrera_fisica`, `barrera_responsabilidad`, `barrera_confianza`, `barrera_acceso` | number | share 0–1 | task weight flagged by each barrier (physical, accountability, trust, access); they overlap |
| `imputado` | boolean | — | true if the group inherits the tasks of its three-digit minor group (7 groups) |
| `rank_l2` | integer | 1 = most delegable | rank by `adi_l2` among `n_occupations` (ties share the best rank) |
| `n_occupations` | integer | count | 433 |

## `country/{iso3}.json`

| field | type | unit | meaning |
|---|---|---|---|
| `type` | string | — | `country` |
| `id`, `iso3` | string | code | ISO 3166-1 alpha-3 |
| `pais` | string | — | country name (World Bank) |
| `ingreso` | string | — | World Bank income group FY2026: `high`, `upper-middle`, `lower-middle`, `low` |
| `region` | string | — | region label used in the atlas |
| `anio` | integer | year | reference year of the ILOSTAT employment structure |
| `resolucion` | string | — | `isco08_2d` or `isco08_1d`: ISCO level of the employment data |
| `adi_l2` | number | share 0–1 | ADI_c: employment-weighted share of task weight at L2 or L3 |
| `l2_lo`, `l2_hi` | number | share 0–1 | 95 % bootstrap interval of `adi_l2` |
| `adi_l3` | number | share 0–1 | employment-weighted share at L3 |
| `adi_share` | number | percent 0–100 | employment-weighted percent of working time delegable |
| `adi_l2_iguales`, `adi_l3_iguales`, `adi_share_iguales` | number | as above | sensitivity: equal weights for unit groups within each reported group |
| `pib_pc_ppp` | number | constant 2021 international $ | GDP per capita, PPP (World Bank) |
| `empleo_total` | integer | persons | total employment used as weights |
| `rank_l2` | integer | 1 = most delegable | rank by `adi_l2` among `n_countries` |
| `n_countries` | integer | count | 146 |

## `index.json`

`name`, `title`, `headline` (world and income-group percentages, intervals, H1 slope, L3 peak in minutes, with the
`claims.jsonl` ids they come from), `coverage` (tasks, unit groups, countries, employment in millions, models),
`endpoints` (path templates), `occupations[]` and `countries[]` (summary rows), plus the common fields.
Percentages in `headline` are in percent 0–100; per-record `adi_l2`/`adi_l3` are shares 0–1.

## Example

```sh
curl -s https://cespial.github.io/delegation-divide/adi/v2026.1/isco/2512.json | jq '{titulo, adi_l2, adi_l3, cite: .cite.text}'
```

Full column definitions and the verbatim L0–L3 levels: `../DATA_DICTIONARY.md`.
